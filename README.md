# AdminPanel

Плагин для **Spigot / Paper** с GUI админ-панелью, системой жалоб на игроков и лёгким анти-читом.

Поддерживает **Minecraft 1.16.5 – 1.21.11** (один jar работает на всех версиях, т.к. код скомпилирован против самого старого API).

---

## Возможности

- **Админ-панель** (`/admin`) — GUI с инструментами модерации и мониторингом игроков.
- **Режим наблюдателя** — вход в spectator через меню, возврат на прежнюю позицию и режим полёта той же командой `/admin`.
- **Жалобы** (`/report <игрок> <причина>`) — поиск игрока без учёта регистра, защита от саморепорта, жалобы не сбрасываются при выходе игрока.
- **Анти-чит** — детекторы Speed / Fly / Killaura с уровнями нарушений (VL) и алертами для персонала.

## Команды

| Команда | Описание | Право |
|---|---|---|
| `/admin` | Открыть админ-панель (или выйти из режима наблюдателя) | `adminpanel.use` |
| `/report <игрок> <причина>` | Пожаловаться на игрока | `adminpanel.report` |

## Права

| Право | Описание | По умолчанию |
|---|---|---|
| `adminpanel.use` | Доступ к админ-панели | `op` |
| `adminpanel.alert` | Получать алерты анти-чита | `op` |
| `adminpanel.report` | Возможность отправлять жалобы | `true` |

## Сборка

Нужны **JDK 16+** и **Maven 3.6+**.

```bash
mvn clean package
```

Готовый jar появится в `target/AdminPanel-<version>-<mcversion>.jar`.

### Сборка под конкретную версию Minecraft

```bash
# Пример: версия для 1.21.11
mvn clean package -Dmc.version=1.21.11 -Dmc.apiversion=1.21
```

Скрипт для сборки всех версий 1.21.x подряд:

```powershell
./build-all.ps1
```

Результат складывается в `dist/`.

## Установка

1. Собрать jar (или взять готовый из релиза).
2. Положить в папку `plugins/` сервера Spigot/Paper.
3. Перезапустить сервер.

---

## Технические детали

- **Компиляция:** Java 16 (bytecode major 60), `maven.compiler.release=16`.
- **api-version:** 1.16 — гарантирует совместимость со всеми версиями 1.16.5 – 1.21.11.
- **GUI:** собственный `MenuHolder` (`InventoryHolder`) — клики отслеживаются по холдеру инвентаря, а не по названию окна, поэтому не задевают чужие инвентари.
- **Хранение данных:** жалобы и уровни нарушений живут в памяти (сбрасываются при рестарте сервера).
